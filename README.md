# Super Solar Panels - Unofficial

An unofficial maintenance fork of Denfop's Super Solar Panels for Minecraft 1.12.2, adding higher-tier solar panels, armor, and electric weapons on top of Advanced Solar Panels.

## Dependencies

- IndustrialCraft 2 (2.8.191+)
- Advanced Solar Panels (4.3.0)
- [AdvSolarPatch-Unofficial](https://github.com/mustardwheat/AdvSolarPatch-Unofficial) (1.3.1+)
